## Git 环境配置

安装 Git，在文件夹右键打开 Git Bash Here；

依次执行命令：`cd`、`ssh-keygen`、`cd .ssh`、`cat id_rsa.pub`，复制输出的公钥；

进入 Gitee，打开个人设置 - SSH 公钥，粘贴公钥完成绑定；

项目文件夹内使用 Git Bash，粘贴仓库 SSH 地址关联仓库；

常用提交命令：`git status`（查看文件状态）、`git add .`（提交所有文件）、`git commit -m "xxx"`（添加提交备注）、`git push`（推送到云端）。

## IDEA 创建 SpringBoot 项目

新建项目选择 Spring Initializr，服务器地址访问异常可改用阿里云镜像 `https://start.aliyun.com`；

项目名：backend，类型选择 Maven，JDK 选用 JDK 17，Java 版本 17，打包方式 Jar；

勾选依赖 Spring Web、PostgreSQL Driver，完成项目创建；

找到项目入口类 `xxxApplication.java`，运行 main 方法；

启动成功默认端口 8080，浏览器访问 `localhost:8080`，出现 Whitelabel Error Page（404 页面）代表项目启动正常。
